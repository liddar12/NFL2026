## Dedupe notes

- Ranks 9–11 all touch the RoS self-learning/backtest honesty surface but are **distinct
  defects with distinct root causes and fixes**, kept separate: #9 = docstring claims the
  wrong code path (backtest_ros.py); #10 = the artifact is regenerated by nothing and shown
  nowhere; #11 = the artifact is validated by nothing. #8 is a separate false-mechanism claim
  in a different file (app/ros.js) about a promotion gate, not the backtest.
- No true duplicates across the four source batches; 11 findings retained from 11 confirmed.

## Tier rationale

- **No P0/P1:** nothing crashes the app, corrupts scored/leaderboard data, or violates a
  hard standing rule (no login/commissioner leak, no market-as-model-input, no build step).
- **P2** = wrong output on a live decision/display surface (missing matchup on the default
  parlays view, phantom lineup rows, overstated RoS in compare, missing QB backups in
  draft). Reach ordering favors surfaces active *now* for all users (#1) over league-shape
  edge cases (#4, #5).
- **P3** = narrower functional edge cases requiring a mis-tap or deep-link (#6, #7) and
  honesty/pipeline-integrity gaps that are developer-facing or currently inert (#8–#11).
